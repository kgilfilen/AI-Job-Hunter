# Artifacts Package

## Directory Overview

The **Artifacts** package is responsible for all filesystem output generated by
AI Career Manager.

Modules in this package organize and persist analysis artifacts. They do not
perform parsing, scoring, AI interaction, repository operations, or business
logic.

### Design Goals

- Separate artifact organization from artifact content generation.
- Produce deterministic, human-readable output.
- Preserve original input for auditing and reproducibility.
- Keep filesystem concerns isolated from business logic.

### Modules

| Module | Responsibility |
|---------|----------------|
| `analysis_artifacts.py` | Writes generated analysis artifacts to disk. |
| `job_artifacts.py` | Organizes per-job artifact directories and preserves original job descriptions. |

---

# analysis_artifacts.py

## Purpose

This module is responsible for persisting generated job-analysis artifacts to
disk.

It does not perform analysis, scoring, parsing, or recommendation logic. Its
job is to take already-created domain objects or text and write them into the
per-job artifact directory in a consistent format.

In architectural terms:

```text
JobService
    ↓
analysis_artifacts
    ↓
filesystem
```

It is an output/persistence utility for generated files.

---

## Public Interface

This module exposes four public artifact-writing functions:

- `save_job_opening()`
- `save_fit_analysis()`
- `save_resume_recommendation()`
- `save_tailored_resume()`

The remaining functions are internal implementation helpers.

---

## Inputs and Outputs

### `save_job_opening(job_opening, job_artifact_directory)`

- Input: `JobOpening` dataclass
- Input: target artifact directory
- Output: `Path` to `job.json`
- Side effect: creates parent directory if needed through `_write_json()`
- File format: UTF-8, pretty-printed JSON

### `save_fit_analysis(fit_analysis, job_artifact_directory)`

- Input: `FitAnalysis` dataclass
- Input: target artifact directory
- Output: `Path` to `_fit.json`
- Side effect: writes or overwrites fit-analysis artifact

### `save_resume_recommendation(recommendation, job_artifact_directory)`

- Input: `ResumeRecommendation` dataclass
- Input: target artifact directory
- Output: `Path` to `_resume_recommendation.json`

### `save_tailored_resume(resume_text, job_artifact_directory)`

- Input: rendered resume text
- Input: target artifact directory
- Output: `Path` to `tailored_resume.md`
- Side effect: creates the artifact directory if necessary
- File format: UTF-8 Markdown

### `_write_json(output_file, value)`

- Input: output path
- Input: dataclass-compatible object
- Output: None
- Side effect: creates parent directories and writes JSON

### `make_json_safe(value)`

- Input: nested Python value
- Output: equivalent value suitable for `json.dumps()`
- Converts:
  - `Enum` → `.value`
  - lists recursively
  - dictionaries recursively

---

## Dependencies

This module depends on:

- `pathlib.Path`
- `json`
- `dataclasses.asdict()`
- `JobOpening`
- `FitAnalysis`
- `ResumeRecommendation`

It has **no dependency** on:

- parsing
- scoring
- AI
- repositories
- user interface
- candidate profiles

---

## Behavioral Specifications

- Artifact writers return the exact path written.
- JSON files use UTF-8 encoding.
- JSON output is formatted with four-space indentation.
- Parent directories are created automatically.
- Existing files are overwritten.
- Enum values are serialized using `.value`.
- Dataclasses are serialized recursively.
- Artifact generation does not mutate domain objects.
- Business logic does not belong in this module.

---

## Invariants

The module guarantees:

- Deterministic artifact filenames.
- Human-readable JSON.
- Automatic directory creation.
- Immutable inputs.
- Independence from UI and database layers.

---

## Current File Contract

```text
<job_artifact_directory>/
    job.json
    _fit.json
    _resume_recommendation.json
    tailored_resume.md
```

These filenames are considered part of the module's public contract.

## Error Behavior

Filesystem and serialization errors propagate naturally.

Examples include:

- permission errors
- invalid output paths
- disk failures
- unsupported serialization types

# job_artifacts.py

## Purpose

This module is responsible for creating and organizing the filesystem structure
used to store artifacts associated with a single job.

Unlike `analysis_artifacts.py`, which writes generated analysis products, this
module manages the directory layout and preserves the original, unmodified job
description exactly as it was received.

```text
JobService
    ↓
job_artifacts
    ↓
filesystem
```

---

## Public Interface

- `get_job_artifact_directory()`
- `write_original_job_artifact()`

---

## Inputs and Outputs

### `get_job_artifact_directory(job_id, artifact_root)`

- Input: integer job identifier
- Input: optional artifact root
- Output: `Path` to the job directory
- Side effect: creates directory if needed

### `write_original_job_artifact(job_id, job_text, artifact_root)`

- Input: job identifier
- Input: original job text
- Input: optional artifact root
- Output: `Path` to `original_job.txt`
- Side effect:
  - creates artifact directory
  - writes UTF-8 text

---

## Dependencies

Depends only on:

- `pathlib.Path`

No dependency on:

- AI
- parsing
- scoring
- repositories
- databases
- candidate profiles
- Streamlit

---

## Behavioral Specifications

- Job IDs must be positive.
- Directories use six-digit zero-padded names.
- Directories are created automatically.
- Original text is preserved exactly.
- UTF-8 encoding is used.
- Existing files are overwritten.
- Functions return the created path.

---

## Invariants

The module guarantees:

- Deterministic directory names.
- Stable artifact locations.
- Immutable original job descriptions.
- Idempotent directory creation.
- Independence from business logic.

---

## Current File Contract

```text
outputs/jobs/
    000017/
        original_job.txt
        job.json
        _fit.json
        _resume_recommendation.json
        tailored_resume.md
```

---

## Error Behavior

Filesystem errors propagate naturally.

Invalid job identifiers raise `ValueError`.

---

---

## Possible Future Enhancements

---

## Overall Responsibility

This module provides the filesystem foundation for every job processed by the
application.

Its responsibility is intentionally narrow:

- determine where artifacts belong
- preserve the original job description
- provide a stable directory structure for subsequent analysis

It contains no parsing, scoring, persistence, AI, or business logic.
